The Vault is Natter's own encrypted store for the secrets of Natter Contexts. The Context file holds only a reference to the Vault entry, never the secret itself.

What's in it

All Vault secrets live in one file, ~/.config/natter/vault.age, encrypted with age to a post-quantum key: the Vault key. Natter holds that key in memory only while it runs. Every read and write decrypts the file again.

How the Vault is created

You don't have to create it yourself. The first time you store a secret in the Vault (a new Context, an edited secret, or Move into Vault), Natter creates the Vault and keeps its key in your OS keyring: macOS Keychain, Windows Credential Manager, or the Secret Service on Linux. From then on it unlocks by itself when Natter starts.

The keyring holds only the Vault key, never your secrets.

Add a backup passphrase

While the keyring holds the only copy of the key, losing the keyring entry (a new machine, a reinstalled OS, a reset keyring) loses the secrets in the Vault. The Contexts page shows a warning until you choose Add a backup passphrase. Natter also won't let you turn the keyring off until there is one.

On a system without a working keyring (headless Linux, WSL, some containers), create the Vault on the Contexts page with a passphrase instead. You can also choose Create it now with a passphrase there before you store anything.

Ways to unlock

MethodHow
OS keyringUnlocks at startup. Toggle it on the Contexts page with OS keyring: on/off.
PassphraseType it on the Contexts page after a restart. Stored as a copy of the Vault key wrapped with your passphrase, in vault.key.age.
Key fileStart Natter with -vault-key natter.key, an age identity you created with age-keygen -pq -o natter.key.

Changing the passphrase or moving the key in or out of the keyring never re-encrypts your secrets: only the copy of the key changes.

A locked Vault

If the Vault is locked, Contexts whose secret is in it can't connect, and say so straight away instead of waiting. Unlock it on the Contexts page and Natter reconnects.
