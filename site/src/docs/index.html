Natter is a desktop app for NATS™ and JetStream that runs on your own machine. It shows you what your deployment is doing (servers, connections, streams, consumers and messages) and lets you act on it.

How it works

When you start Natter, it serves its UI on 127.0.0.1 and shows it in a window of its own (the desktop app), or in a browser if you use the command-line binary. The window only ever talks to Natter, never to NATS directly, and Natter only accepts windows and browsers signed in with its Launch token.

It connects through a Context: a server URL plus the credentials to reach it, exactly like a nats CLI context. Natter reads the contexts you already made with nats context add, and can keep its own. One Context is active at a time; switch from the sidebar or with ⌘K.

What you can do

Overview & ConnectionsRates, servers, storage, and every client connected. StreamsCreate, edit, purge and delete JetStream streams. ConsumersSee lag across every stream; manage every option. Message browserScroll, filter and open messages without side effects. Publish / RequestSend test messages and requests; save them as examples. Live tailWatch a subject live, rate-capped.

Where to start

  1. Install the desktop app for your system.
  2. Follow the Quick start to open it and connect to a server.
  3. Read about Read-only mode before you point it at production.
