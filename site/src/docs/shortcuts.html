Natter is built to be driven from the keyboard. ⌘ is Ctrl on Linux and Windows.

Command palette

Press ⌘ K anywhere, or click the search box in the top bar. Type to find:

  • Go to: any screen.
  • Streams: open any stream by name.
  • Switch Context: connect to another Context.
  • Actions: create a stream, publish a message, tail a subject.

Everywhere

KeysAction
⌘ KOpen the command palette.
EscClose a dialog, the palette or an open message.
TabMove between controls. Every control shows a visible focus ring.
