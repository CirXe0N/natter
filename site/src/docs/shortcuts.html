Natter is built to be driven from the keyboard. ⌘ is Ctrl on Linux and Windows.

Everywhere

KeysAction
EscClose a dialog or an open message.
TabMove between controls. Every control shows a visible focus ring.

Message browser

KeysAction
EnterApply the subject filter, or jump to the typed sequence.
↑ / kPrevious message, when one is open.
↓ / jNext message, when one is open.

Publish / Request

KeysAction
⌘ EnterPublish or send.
