Natter is a desktop app for Linux, macOS and Windows: a native window with a tray icon and an installer. For terminals and servers there is also a single command-line binary, natter. Both have the web UI built in, and there's nothing else to install.

Install the desktop app

Each release has the desktop app as an installer per system:

SystemDownload
macOS (Apple silicon and Intel)natter-desktop_darwin_universal.dmg. Drag Natter to Applications.
Windows x86-64natter-desktop_windows_amd64-setup.exe. Installs for your user only, no admin rights needed.
Linux x86-64natter_{{VERSION}}_amd64.deb, natter-{{VERSION}}-1.x86_64.rpm, or natter-desktop_linux_amd64.AppImage.

On Linux the app needs GTK 4 and WebKitGTK 6.0. The deb and rpm packages pull them in; the AppImage expects them on the system. More about the desktop app.

Download the command-line binary

For a server, a script, or a machine without a desktop, each release also has one archive per system. Each holds the natter binary (natter.exe on Windows) and THIRD_PARTY_LICENSES.txt. It serves the same UI on localhost and opens it in a browser.

SystemArchive
Linux x86-64natter_{{VERSION}}_linux_amd64.tar.gz
Linux ARM64natter_{{VERSION}}_linux_arm64.tar.gz
macOS Apple siliconnatter_{{VERSION}}_darwin_arm64.tar.gz
macOS Intelnatter_{{VERSION}}_darwin_amd64.tar.gz
Windows x86-64natter_{{VERSION}}_windows_amd64.zip
Windows ARM64natter_{{VERSION}}_windows_arm64.zip

Unpack it and put the binary somewhere on your PATH, for example on Linux or macOS:

tar xzf natter_{{VERSION}}_linux_amd64.tar.gz
install -m 755 natter ~/.local/bin/

Verify the download

Every release has a checksums.txt for the command-line archives and a checksums-desktop.txt for the desktop installers. Download the one that matches next to your file and check:

sha256sum -c checksums-desktop.txt --ignore-missing

On macOS use shasum -a 256 -c …. Each command-line archive also has an SBOM (.sbom.json) listing exactly what is inside.

Install from source

With Go 1.26 or newer, go install builds the command-line binary with the UI included:

go install github.com/CirXe0N/natter/cmd/natter@v{{VERSION}}

A binary you build yourself was never downloaded, so it gets no first-run warning. go install doesn't build the desktop window; use the installers for that.

First-run warnings on macOS and Windows

The desktop app and the release binaries aren't signed by Apple or Microsoft yet, so both systems warn the first time you run a downloaded copy. Verify the checksum first, then:

macOS

macOS says Apple could not check Natter for malicious software. Try to open it once, then open System Settings → Privacy & Security, find the message about Natter and choose Open Anyway.

For the command-line binary you can instead remove the quarantine flag your browser added, then run it again:

xattr -d com.apple.quarantine ./natter

A launcher entry made by natter install-desktop is created on your Mac, not downloaded, so it has no flag.

Windows

Running the installer or natter.exe from Explorer shows Windows protected your PC. Choose More info, then Run anyway. Or clear the downloaded-file mark first, in PowerShell:

Unblock-File .\natter.exe

Smart App Control

On Windows 11, Smart App Control can block unsigned programs without offering Run anyway. Natter then only runs with Smart App Control turned off, in Windows Security → App & browser control.
