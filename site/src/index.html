Built for operators who live in the terminal.

Safe by default

A console you can point at production.

Natter is built so that looking never changes anything, and changing anything is deliberate.

Read the security model →
  • Localhost, with a Launch token. It binds to 127.0.0.1 and checks Host and Origin on every request. The desktop app signs itself in; a browser needs the one-off Launch token to get a session.
  • Read-only mode per Context. Lock a Context and Natter refuses every change and every send, requests included. Browsing still works.
  • Browsing has no side effects. No durable consumers, no acks, no moved positions. Natter's own browsing consumers are labelled, not hidden.
  • No plaintext secrets. Natter never writes one. It flags the ones in your natscli contexts and moves them into the Vault for you.

Get started

From download to your first stream in a minute.

  1. 01

    Install

    Download the installer for your system below. Prefer a terminal? Build the command-line binary with Go 1.26+.

    go install github.com/CirXe0N/natter/cmd/natter@latest
  2. 02

    Open

    Start Natter from your app launcher: it opens already signed in, with no token to copy. From the command line, natter open does the same in a browser app window.

    natter open
  3. 03

    Connect

    Pick one of your natscli contexts, or create one with the server URL and a secret. That's it.

    nats://127.0.0.1:4222
